# Catálogo de dominios universitarios

`world_universities_and_domains.json` es una copia local del proyecto
[University Domains and Names Data List](https://github.com/Hipo/university-domains-list),
descargada el 6 de octubre de 2026. Se conserva localmente para que el registro
no dependa de la disponibilidad de una API externa.

La licencia original está en `UNIVERSITY_DOMAINS_LICENSE.txt`. Los dominios que
todavía no estén en el catálogo pueden agregarse por configuración mediante
`ADDITIONAL_UNIVERSITY_EMAIL_DOMAINS`, sin modificar el código.
